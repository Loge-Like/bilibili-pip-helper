哔哩哔哩视频浮窗定位助手 v2.0： 一个用于 B 站视频页面的 Tampermonkey 脚本，提供画中画悬浮播放、页面自动定位和动态视觉特效。

![展示](https://github.com/Loge-Like/bilibili-pip-helper/blob/main/images/effect_orb.jpg)

<br><br>

📝 更新

    v2.0 全新体验：新增画中画动态特效、自动化等功能
    v1.1 新增拖拽画中画调整尺寸

<br>

📅 未来更新计划

    更多动态特效，同时也适用于非画中画情形

    画中画可使用浏览器小窗

<br>

🎯 页面定位系统

    页面加载 / 宽屏 / 全屏退出 / 画中画退出时自动水平居中

    可配置垂直偏移量，基于页面顶部或视频顶部计算

<br>

🎬 画中画系统

    将视频弹出为可拖拽调节尺寸的浮动窗口
    
    可配置向下滚动自动缩小、向上滚动恢复
    
    拖拽边框调整尺寸，支持临时调节或永久保存
    
    背景遮罩：黑色或自适应背景色，浓度可调节
    
    背景模糊：仅画中画模糊或悬浮评论模式，可配合封面图使用

    动态特效：六种特效（星光、细雨、光球、流星、边缘光晕、视频投影），支持随机切换。

<br>

![面板](https://github.com/Loge-Like/bilibili-pip-helper/blob/main/images/panel_pip.jpg)

<br><br>

⏱️ 自动化
    
    页面加载时可选自动开启画中画 / 宽屏 / 网页全屏
    
    开启画中画自动播放，退出自动暂停
    
    播放 / 暂停时自动进入 / 退出浏览器全屏

<br>

![面板](https://github.com/Loge-Like/bilibili-pip-helper/blob/main/images/panel_automation.jpg)

<br><br>

⌨️ 其他功能

    性能模式：禁用过渡动画，降低资源消耗

    防止空格键页面下滚

    隐藏播放页面滚动条
    
    可选显示 / 隐藏画中画按钮、尺寸按钮、关闭按钮

🛠️ 使用说明

    脚本安装后，在B站视频页面会自动在底部控制栏添加一个画中画按钮（📺 图标）。点击即可开启/关闭画中画模式。

    点击 Tampermonkey 菜单中的"⚙ 设置"打开配置面板
